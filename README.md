## Tema Bisnis

Layanan Langganan Makanan Sehat Harian Siap Santap (*Healthy Meal Subscription Service*).

SEHATIN merupakan layanan berlangganan makanan sehat harian yang menyediakan pilihan menu praktis dan bergizi sesuai kebutuhan pelanggan.

## Layanan Kami

1. **Paket Kalori Terkontrol** — Pilihan makanan dengan porsi dan kalori yang terukur.
2. **Paket Pembentukan Otot** — Menu tinggi protein untuk mendukung pembentukan otot.
3. **Paket Sehat Keluarga** — Pilihan makanan sehat untuk kebutuhan keluarga.
